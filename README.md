# OSSCALC
Open Source Scientific Calculator
## Intro

OSSCALC (Project UMA) is a programmable scientific calculator designed to be highly modular and deeply programmable. It runs (and is programmed in) a stack based language called UMAScript.

## State of the Project
OSSCALC is currently in early development, we have not built it yet.

## Hack Club
Hack Club is a world-wide non-profit organization inspiring teens aged 13-18 to build cool stuff. OSSCALC is part of the Hack Club Forge program.

## How to follow us
We specify everything before it goes into the design. If it isn't in the docs folder, it won't be in OSSCALC. Rule of thumb: We (or maybe just myself, Llewi) obsessively document the process behind OSSCALC's design and building.
